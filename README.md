# Mini TLS Server/Client

> [Russian version](README_RU.md)

> [China version](README_CN.md)

## Project Description

A self-contained mini TLS server and TLS client project written in pure C/C++, built on top of the **crypery** library (TLS 1.2/1.3).

- The **server** listens on a TCP port, generates an RSA-2048 key and a self-signed X.509 certificate at startup, performs a TLS handshake with each connecting client (automatic TLS 1.2 or 1.3 version negotiation), and echoes back all received data.
- The **client** connects to the server, performs the handshake, prints the negotiated session parameters, and exchanges messages with the server in interactive or non-interactive mode.

There are no external dependencies: all cryptographic algorithms are implemented from scratch inside the crypery library.

## Project Features

- **TLS 1.2 and TLS 1.3** with automatic version negotiation (the server accepts both).
- **Cryptography**: `TLS_AES_128_GCM_SHA256` (TLS 1.3), `ECDHE-RSA-AES128-GCM-SHA256` (TLS 1.2).
- **Key exchange**: X25519 (TLS 1.3), ECDHE on the P-256 curve (TLS 1.2).
- A **self-signed certificate** is generated by the server at startup - no certificate or key files are required.
- **Pure C with no external crypto libraries**: AES-128-GCM, SHA-256, HMAC-SHA256, HKDF, RSA-2048, ECDH, X.509 - all implemented from scratch.
- **Portability**: Windows (MinGW, Winsock) and Unix-like systems (BSD sockets).
- **Two client modes**: interactive (dialog with the server) and non-interactive (reading lines from stdin).
- **Echo server**: returns all received data - convenient for testing the TLS channel.
- After the handshake, the client prints the negotiated TLS version, cipher suite, and key exchange method.

## Modules Used (crypery library)

The examples use the `tls` module directly; at build time all library modules are compiled:

- **tls** - the basic cryptographic layer: TLS 1.2/1.3 handshake (client/server), AES-128-GCM, SHA-256, HMAC-SHA256, RSA-2048, ECDH (P-256, X25519), X.509 certificate generation and parsing.
- **ssl** - an OpenSSL-compatible wrapper over the built-in TLS (SSL_CTX/SSL API, timeouts, peer certificate verification).
- **http** - an HTTP/1.1 server over TCP/TLS (routing, static files, WebSocket, SSE).
- **url** - an HTTP/HTTPS client (curl-like API, redirects, chunked encoding).

## Compilation

### Windows

GCC (MinGW-w64) must be in PATH.

Run the build script:

```bat
build_tls.bat
```

The script compiles the entire crypery library together with the examples:

| Target file | Sources |
|---|---|
| `tls_client.exe` | `crypery/*.c` + `tls_client.c` |
| `tls_server.exe` | `crypery/*.c` + `tls_server.c` |

Compilation flags: `-O2` (optimization), `-I./crypery` (library headers), `-DHTTP_NO_GZIP` (disables gzip and the zlib dependency), `-lws2_32` (Winsock).

### Linux

GCC must be installed (e.g. `apt-get install gcc` on Debian/Ubuntu).

Run the build script:

```sh
chmod +x build_tls.sh
./build_tls.sh
```

The script compiles the entire crypery library together with the examples:

| Target file | Sources |
|---|---|
| `tls_client` | `crypery/*.c` + `tls_client.c` |
| `tls_server` | `crypery/*.c` + `tls_server.c` |

Compilation flags: `-O2` (optimization), `-I./crypery` (library headers), `-DHTTP_NO_GZIP` (disables gzip and the zlib dependency), `-lpthread` (POSIX threads).

## Usage

### 1. Starting the server

```bat
tls_server.exe:: default port - 2000
tls_server.exe 8443:: custom port
```

The server generates the key and certificate, then waits for connections.

### 2. Starting the client (in a separate terminal)

```bat
tls_client.exe:: localhost:2000
tls_client.exe 127.0.0.1 8443:: custom host and port
```

### 3. Interactive mode

After the handshake, the client prints the session parameters and information from the server. Type a message and press Enter - the server will echo it back:

```
Client: hello
Server: hello
```

To exit: the `exit` command or the Esc key.

### 4. Non-interactive mode

If stdin is not a terminal, the client reads lines from stdin and sends each one over TLS:

```bat
echo "test" | tls_client.exe
```

### Session example

```
Connected to localhost:2000
Client TLS: 1.3
Server TLS: 1.2/1.3 (1.3)
Cipher Suite: TLS_AES_128_GCM_SHA256
Key Exchange: X25519
Interactive:  yes
Enter message ('exit' or esc to quit):
Client: hello
Server: hello
Exiting...
Disconnected from localhost:2000
```
