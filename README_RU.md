# Мини TLS Server/Client

> [English version](README.md)

> [China version](README_CN.md)

## Описание проекта

Самодостаточный мини-проект TLS-сервера и TLS-клиента на чистом C/CPP, построенный на библиотеке **crypery** (TLS 1.2/1.3).

- **Сервер** слушает TCP-порт, при старте генерирует RSA-2048 ключ и самоподписанный X.509-сертификат, проводит TLS-рукопожатие с каждым подключившимся клиентом (автовыбор версии TLS 1.2 или 1.3) и возвращает (эхо) все полученные данные.
- **Клиент** подключается к серверу, проводит рукопожатие, выводит согласованные параметры сессии и обменивается сообщениями с сервером в интерактивном или неинтерактивном режиме.

Внешних зависимостей нет: все криптоалгоритмы реализованы с нуля внутри библиотеки crypery.

## Особенности проекта

- **TLS 1.2 и TLS 1.3** с автоматическим согласованием версии (сервер принимает обе).
- **Криптография**: `TLS_AES_128_GCM_SHA256` (TLS 1.3), `ECDHE-RSA-AES128-GCM-SHA256` (TLS 1.2).
- **Обмен ключами**: X25519 (TLS 1.3), ECDHE на кривой P-256 (TLS 1.2).
- **Самоподписанный сертификат** генерируется сервером в момент запуска - файлы сертификата и ключа не требуются.
- **Чистый C без внешних криптобиблиотек**: AES-128-GCM, SHA-256, HMAC-SHA256, HKDF, RSA-2048, ECDH, X.509 - всё реализовано с нуля.
- **Портативность**: Windows (MinGW, Winsock) и Unix-подобные системы (BSD-сокеты).
- **Два режима клиента**: интерактивный (диалог с сервером) и неинтерактивный (чтение строк из stdin).
- **Эхо-сервер**: возвращает все полученные данные - удобно для проверки TLS-канала.
- После рукопожатия клиент выводит согласованную версию TLS, шифр-свиту и метод обмена ключами.

## Используемые модули (библиотека crypery)

Примеры используют модуль `tls` напрямую; при сборке компилируются все модули библиотеки:

- **tls** - базовый криптографический слой: рукопожатие TLS 1.2/1.3 (клиент/сервер), AES-128-GCM, SHA-256, HMAC-SHA256, RSA-2048, ECDH (P-256, X25519), генерация и разбор X.509-сертификатов.
- **ssl** - OpenSSL-совместимая обёртка над встроенным TLS (API SSL_CTX/SSL, таймауты, проверка сертификата стороны).
- **http** - HTTP/1.1-сервер поверх TCP/TLS (маршрутизация, статические файлы, WebSocket, SSE).
- **url** - HTTP/HTTPS-клиент (curl-подобный API, редиректы, chunked-кодирование).

## Компиляция

### Windows

Требуется GCC (MinGW-w64) в PATH.

Запуск скрипта сборки:

```bat
build_tls.bat
```

Скрипт компилирует библиотеку crypery целиком вместе с примерами:

| Целевой файл | Источники |
|---|---|
| `tls_client.exe` | `crypery/*.c` + `tls_client.c` |
| `tls_server.exe` | `crypery/*.c` + `tls_server.c` |

Флаги компиляции: `-O2` (оптимизация), `-I./crypery` (заголовки библиотеки), `-DHTTP_NO_GZIP` (отключение gzip и зависимости от zlib), `-lws2_32` (Winsock).

### Linux

Требуется GCC (например, `apt-get install gcc` на Debian/Ubuntu).

Запуск скрипта сборки:

```sh
chmod +x build_tls.sh
./build_tls.sh
```

Скрипт компилирует библиотеку crypery целиком вместе с примерами:

| Целевой файл | Источники |
|---|---|
| `tls_client` | `crypery/*.c` + `tls_client.c` |
| `tls_server` | `crypery/*.c` + `tls_server.c` |

Флаги компиляции: `-O2` (оптимизация), `-I./crypery` (заголовки библиотеки), `-DHTTP_NO_GZIP` (отключение gzip и зависимости от zlib), `-lpthread` (потоки POSIX).

## Использование

### 1. Запуск сервера

```bat
tls_server.exe:: порт по умолчанию - 2000
tls_server.exe 8443:: свой порт
```

Сервер генерирует ключ и сертификат, затем ожидает подключения.

### 2. Запуск клиента (в отдельном терминале)

```bat
tls_client.exe:: localhost:2000
tls_client.exe 127.0.0.1 8443:: свой хост и порт
```

### 3. Интерактивный режим

После рукопожатия клиент выводит параметры сессии и информацию от сервера. Введите сообщение и нажмите Enter - сервер вернёт его эхом:

```
Client: hello
Server: hello
```

Выход: команда `exit` или клавиша Esc.

### 4. Неинтерактивный режим

Если stdin не является терминалом, клиент читает строки из stdin и отправляет каждую по TLS:

```bat
echo "test" | tls_client.exe
```

### Пример сессии

```
Connected to localhost:2000
Client TLS: 1.3
Server TLS: 1.2/1.3 (1.3)
Cipher Suite: TLS_AES_128_GCM_SHA256
Key Exchange: X25519
Interactive:  yes
Enter message ('exit' or esc to quit):
Client: hello
Server: hello
Exiting...
Disconnected from localhost:2000
```
